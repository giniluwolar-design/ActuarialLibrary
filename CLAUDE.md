# Shared project instructions

Read `AGENTS.md`, `docs/project/HANDOVER.md` and `docs/project/LESSONS.md` before work. Use those files for durable state and feedback; do not create a second source of truth. Preserve the local-data boundary described there.

## Agent skills

### Issue tracker

Issues, specifications and Wayfinder maps are tracked in GitHub Issues for `giniluwolar-design/ActuarialLibrary`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage roles with their default label names. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with a root `CONTEXT.md` and system-wide ADRs under `docs/adr/`. See `docs/agents/domain.md`.
